The `uc` CLI is local-first and needs almost no configuration. Everything lives under
`~/.ultracontext/` (not XDG):

| Path | Purpose |
|------|---------|
| `~/.ultracontext/uc.db` | Local SQLite database — your contexts |
| `~/.ultracontext/config.json` | Optional hosted-backend credentials |

<Info>Run `uc init` to create this directory and the local store interactively.</Info>

## Config file

`~/.ultracontext/config.json` holds only the optional hosted-backend slice. It is
written atomically (temp file + rename) by `uc init`.

```json JSON
{
    "baseUrl": "https://api.ultracontext.ai",
    "apiKey": "uc_live_..."
}
```

Both keys are optional. With neither, the CLI is local-only. With both, context
commands automatically talk to the hosted [Context API](/api-reference/introduction)
unless you override at the command line.

## Environment variables

Environment variables override the config file.

| Variable | Description |
|----------|-------------|
| `UC_API_URL` | Hosted API base url (overrides `baseUrl`) |
| `UC_API_KEY` | Hosted API key (overrides `apiKey`) |
| `UC_DB_URL` | Local SQLite url (overrides `~/.ultracontext/uc.db`) |
| `UC_CONTEXT` | Default context id for targeted verbs (`append` / `get` / `update` / `delete`) |

```bash bash
# one-off command against the hosted API
UC_API_KEY=uc_live_... uc context append "$id" "synced note"

# set a default context, then drop the id from each verb
export UC_CONTEXT=ctx_abc123
echo "another note" | uc context append    # body via stdin (id from UC_CONTEXT)

# point at a different local database (e.g. for tests)
UC_DB_URL=file:/tmp/scratch.db uc context list
```

## Local vs remote

The CLI picks a backend per command:

1. `--remote` on a context command forces the hosted API.
2. Otherwise, if a base url **and** api key are configured (env or file), it uses the hosted API.
3. Otherwise, it uses the local SQLite store.

```bash bash
uc context list                 # local-first (default)
uc context list --remote        # hosted API for this command
```

## Precedence

Resolution order for hosted credentials:

1. Environment variables (`UC_API_URL`, `UC_API_KEY`)
2. `~/.ultracontext/config.json`
3. Local-only (no remote)

## Check your setup

```bash bash
uc doctor
```

`uc doctor` reports the uc version, whether `~/.ultracontext` exists, local DB
reachability, `mutagen` availability (for `uc mirror`), remote reachability (when
configured), and which credential source is in effect.
