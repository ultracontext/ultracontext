## Prerequisites

- **Node.js >= 22**

That's it. The `uc` CLI is **local-first** — it stores context in a local SQLite
database and needs no API key to start. A hosted [Context API key](https://ultracontext.ai)
(or a [self-hosted](/guides/self-hosting) API) is optional, for syncing across machines.

## 1. Install

One install gives you both the `uc` binary and the [SDK](/sdk).

```bash bash
npm install -g ultracontext
```

## 2. Initialize

```bash bash
uc init
```

This sets up the local store at `~/.ultracontext`. Run it interactively to optionally
connect a hosted backend, or `uc init --yes` to accept local-only defaults.

## 3. Capture and read context

```bash bash
id=$(uc context create)                              # create a context → prints its id
uc context append "$id" "remember: deploy uses Fly.io"   # append a message
uc context get "$id"                                 # read the context
uc context get "$id" --history                       # time-travel through versions
uc context list                                      # list all contexts
```

UltraContext manages **many contexts explicitly** — there is no default context. Every
targeted verb takes a context id, so you always know exactly what you're reading or
writing. Set `UC_CONTEXT` to drop the id from each command:

```bash bash
export UC_CONTEXT=$id                 # set once
echo "another note" | uc context append      # body via stdin (id from UC_CONTEXT)
uc context get
```

<Note>With `UC_CONTEXT` set, the lone positional on `uc context append` is still read as the context id — so pipe the body via stdin or pass `--message '{...}'`.</Note>

Fork or clone with `uc context create --from <id>`. Attach `--meta key=val` (repeatable) on any
verb. See the [CLI reference](/fundamentals/cli) for the full command tree.

<Tip>Every command is pipe-aware: add <code>--json</code> (or pipe stdout) for machine-readable output. Run <code>uc commands --json</code> for the authoritative command tree.</Tip>

## 4. Add MCP Server

Give your agents access to context from other agents.

### Claude Code

```bash bash
claude mcp add ultracontext -- npx tsx /path/to/ultracontext/apps/mcp-server/src/stdio.ts
```

### Codex

Add to `~/.codex/config.toml`:

```toml TOML
[mcp_servers.ultracontext]
command = "npx"
args = ["tsx", "/path/to/ultracontext/apps/mcp-server/src/stdio.ts"]
```

<Info>The MCP server reads your API key from `~/.ultracontext/config.json` automatically -- the same config file used by the CLI.</Info>

## 5. Try it

Ask your agent:

- *"What did Codex do last?"*
- *"Show me Claude Code sessions in /Users/alice/Code/myapp"*
- *"What happened on my Mac mini today?"*
- *"List all sessions from the last 24 hours"*
