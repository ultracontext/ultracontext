  <h3>Context that goes beyond.</h3>
  <p>Agents, sessions, machines, teams. Anything.</p>
</div>

---

UltraContext is an open-source context toolkit for AI agents. One interface to work with context of any shape, in any place. Lightweight, unopinionated, and extensible.

A small Rust kernel runs everywhere. Everything else is a driver.

Use it to build:

- an agentic Dropbox
- a company brain
- continuous data ingestors
- agent harnesses
- agent-friendly access to any system
- drivers for devices with no CLI, such as an iPhone
- edge agents
