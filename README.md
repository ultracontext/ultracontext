  <h1>UltraContext</h1>
  <h3>Context that goes beyond.</h3>
  <p>Agents, sessions, machines, teams. Anything.</p>
</div>

---

UltraContext is an open-source context toolkit for AI agents. A small, fast Rust kernel runs everywhere. Everything else is a driver. Drivers connect agents, systems, and devices, keep your context up to date, and make all of it searchable. One interface to context of any shape, in any place. Use it to build an agentic Dropbox, a company brain, a custom harness, or an edge agent.
